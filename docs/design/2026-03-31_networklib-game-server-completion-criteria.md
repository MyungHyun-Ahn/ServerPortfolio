# 기획 노트

## 1. 배경
- `docs/design/2026-03-31_networklib-game-server-refactoring-plan.md`는 `NetworkLib`를 MMORPG 서버용 코어 라이브러리로 정리하기 위한 큰 계획 문서다.
- 하지만 계획 문서만으로는 "어느 시점에 이 기획이 완료되었다고 볼 수 있는지"가 모호할 수 있다.
- 따라서 이번 문서는 해당 기획의 완료 조건, 중간 점검 기준, 증빙 문서를 명확히 하기 위한 판단 기준 문서다.

## 2. 목표
- `NetworkLib` 리팩터링 기획이 완료되었는지 판단할 기준을 문서로 고정한다.
- 각 단계별로 무엇이 끝나야 "완료"라고 볼 수 있는지 구분한다.
- 코드 변경뿐 아니라 빌드, 런타임 검증, 문서 증빙까지 함께 확인할 수 있도록 한다.

## 3. 비목표
- 이 문서는 새 기능 설계 문서가 아니다.
- 이 문서 자체가 리팩터링 우선순위를 다시 정하는 것이 목적은 아니다.
- MMORPG 전체 서버 개발 완료 기준을 정의하지 않는다.

## 4. 완료 판단 대상
- 대상 기획:
  - `docs/design/2026-03-31_networklib-game-server-refactoring-plan.md`
- 판단 범위:
  - `NetworkLib` 코어 정리
  - 세션 수명주기 보강
  - 콘텐츠 계층 경계 정리
  - 패킷 처리 구조 일반화
  - 새 실행 프로젝트 골격 마련

## 5. 완료 판단 기준
### 5-1. 1단계 완료 기준: 코어와 샘플 경계 정리
- 완료 조건:
  - `NetworkLib`에 남길 책임과 `EchoServer` 같은 샘플 앱으로 남길 책임이 문서와 코드 기준으로 구분되어 있다.
  - 모니터링, 키 입력 기반 시스템 작업, Echo 전용 흐름이 코어 필수 요소가 아니라는 점이 정리되어 있다.
- 증빙 문서:
  - 관련 설계 문서
  - 필요 시 코드 리뷰 문서
- 현재 상태:
  - 부분 완료

### 5-2. 2단계 완료 기준: 세션 수명주기 안전성 보강
- 완료 조건:
  - 세션 획득 규칙이 공통 경로로 정리되어 있다.
  - 세션 해제 후 세션 배열 슬롯 무효화 규칙이 반영되어 있다.
  - 콘텐츠 이동/수신 처리에서 세션 재검증이 들어가 있다.
  - 빌드와 반복 접속 런타임 테스트 결과가 남아 있다.
- 증빙 문서:
  - `docs/code-review/2026-03-31_networklib-session-guard-refactoring-review.md`
- 현재 상태:
  - 1차 범위 완료

### 5-3. 3단계 완료 기준: 콘텐츠 계층 인터페이스 정리
- 완료 조건:
  - `CBaseContents`가 전역 서버 상태와 세션 배열을 직접 다루는 범위가 줄어들었다.
  - 콘텐츠 계층이 의존하는 기능이 최소 인터페이스로 정리되어 있다.
  - `void* objectPtr` 기반 이동 데이터 대체 방향이 코드 또는 설계로 반영되어 있다.
- 증빙 문서:
  - 후속 설계 문서
  - 관련 코드 리뷰 문서
- 현재 상태:
  - 미완료

### 5-4. 4단계 완료 기준: 패킷 처리 구조 일반화
- 완료 조건:
  - Echo 예제에 종속되지 않는 공용 패킷 처리 경계가 존재한다.
  - 패킷 디스패치 방식이 문서나 코드로 정리되어 있다.
  - 최소한 한 개 이상의 상위 서버 프로젝트가 공통 패킷 처리 구조를 통해 동작한다.
- 증빙 문서:
  - 패킷 디스패처 설계 문서
  - 관련 코드 리뷰 문서
- 현재 상태:
  - 미완료

### 5-5. 5단계 완료 기준: 새 실행 프로젝트 골격 마련
- 완료 조건:
  - `EchoServer`와 별도로 MMORPG 전환용 실행 프로젝트가 존재한다.
  - 해당 프로젝트가 `NetworkLib` 코어를 사용해 빌드 및 실행된다.
  - `TestClient` 또는 동등한 도구로 최소 접속/송수신 검증이 가능하다.
- 증빙 문서:
  - 새 실행 프로젝트 설계 문서
  - 빌드/런타임 검증 기록
- 현재 상태:
  - 미완료

## 6. 최종 완료 기준
- 아래 조건을 모두 만족하면 `NetworkLib` 게임 서버 코어 리팩터링 기획이 완료된 것으로 판단한다.
- 판단 조건:
  - 단계 1부터 5까지의 완료 기준이 모두 충족됐다.
  - `Portfolio.sln` 또는 동등한 빌드 기준으로 관련 프로젝트가 빌드 가능하다.
  - 반복 접속/종료를 포함한 런타임 검증 결과가 문서로 남아 있다.
  - 코어/샘플 앱/실행 프로젝트의 경계가 문서와 코드에서 일관된다.

## 7. 현재 시점 판정
- 현재 판정:
  - 진행 중
- 근거:
  - 2단계 세션 수명주기 보강은 1차 범위가 반영됐고 런타임 테스트도 통과했다.
  - 그러나 코어와 샘플 앱의 경계 정리, 콘텐츠 인터페이스 정리, 패킷 처리 일반화, 새 실행 프로젝트 골격은 아직 완료 기준을 충족하지 못했다.

## 8. 다음 확인 항목
- `Stop()` 종료 구조 개선을 2단계 후속으로 포함할지 결정
- 콘텐츠 계층 인터페이스 정리 작업을 다음 리팩터링 대상으로 올릴지 결정
- `WorldServer` 같은 새 실행 프로젝트 골격 문서를 언제 만들지 결정
